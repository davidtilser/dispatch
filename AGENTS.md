# Repository instructions

## Scope and ownership

- Keep application code in TypeScript. See README.md for the agreed stack and owners.
- This is a starter. Do not add full product flows unless requested.
- Coordinate shared contract changes in packages/contracts with their consumers.
- Run npm run check before committing implementation changes.
- Keep secrets out of Git and browser bundles.

## Git and GitHub identity

- For all new commits, use davidtilser as both author and committer name, with davidtilser@gmail.com as the email.
- Before committing, verify git var GIT_AUTHOR_IDENT and git var GIT_COMMITTER_IDENT; correct conflicting overrides.
- Verify the active GitHub account before pushing. Use authenticated davidtilser credentials, never tilser.
